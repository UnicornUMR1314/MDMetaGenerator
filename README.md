# MD文章meta信息生成器 - 增强版

一个基于Python Tkinter的现代化GUI工具，专注于为Markdown文章生成完整的meta信息，自动生成符合Hugo格式标准的Markdown文件。支持智能记忆功能和自定义分类标签管理。

## 🎯 新增功能特性

### 记忆功能
- ✅ **SQLite数据库存储**：所有配置和历史记录都保存在本地数据库
- ✅ **智能记忆**：记住最近使用的标签、分类、作者等信息
- ✅ **历史记录**：保存文章生成历史，支持一键加载之前的配置
- ✅ **使用频率统计**：根据使用频率排序选项，越常用的越靠前

### 分类标签自定义管理
- ✅ **动态管理**：支持标签、分类、作者、系列的自定义增删
- ✅ **管理界面**：独立的标签管理窗口，操作简单直观
- ✅ **实时更新**：添加/删除后实时更新下拉列表
- ✅ **数据持久化**：所有自定义数据保存在SQLite数据库

### 配置管理
- ✅ **可视化配置**：独立的配置管理界面
- ✅ **默认设置**：可自定义所有默认值（作者、路径、功能开关等）
- ✅ **配置保存**：配置变更自动保存到数据库
- ✅ **多标签页界面**：文章生成、配置管理、历史记录分离

## 🚀 原有功能

- ✅ 图形化界面选择文章meta信息
- ✅ 自动生成Hugo格式的Front Matter
- ✅ 支持中文和英文双语生成
- ✅ 实时预览生成的Markdown内容

## 🎯 使用方法

### 1. 首次运行
```bash
python main.py
```

### 2. 管理分类标签
- 在"文章生成"标签页，每个下拉框旁边都有"管理"按钮
- 点击"管理"可以添加、删除标签、分类、作者、系列
- 所有数据自动保存，下次打开程序时仍然存在

### 3. 配置默认设置
- 切换到"配置管理"标签页
- 设置默认作者、保存路径、功能开关等
- 点击"保存配置"使设置生效

### 4. 使用历史记录
- 切换到"历史记录"标签页
- 查看之前生成的文章列表
- 选择记录点击"加载选中记录"可快速填充表单

### 5. 生成文章
- 填写文章信息（程序会记住常用的选项）
- 选择语言和保存路径
- 点击"生成"创建Markdown文件

## 📊 数据库结构

### categories表
- 存储标签、分类、作者、系列

### history表
- 存储文章生成历史
- 记录标题、作者、标签、分类等信息
- 支持快速加载历史配置

### settings表
- 存储所有默认配置
- 支持配置持久化

## 📋 生成的文件格式

与之前版本相同，生成标准的Hugo格式Markdown文件：

```markdown
---
title: "文章标题"
subtitle: "文章子标题"
date: "2025-11-20 10:30:00"
lastmod: "2025-11-20 10:30:00"
draft: true
authors:
- "作者名称"
description: "文章摘要"
tags:
- "标签1"
categories:
- "分类1"
toc:
  enable: true
  auto: true
---

<!--more-->

## 摘要
文章摘要内容

## 正文
在这里添加正文内容...
```

## 💡 使用建议

1. **首次使用**：先配置默认作者和常用标签
2. **日常使用**：利用历史记录快速复用相似配置
3. **标签管理**：定期整理不常用的标签，保持列表简洁
4. **配置备份**：数据库文件`article_generator.db`可以备份和迁移

## 🔍 注意事项

- 数据库文件`article_generator.db`会自动创建在程序目录
- 支持多人使用，每个人的配置独立保存
- 历史记录可以清空，但不会影响已生成的文件
- 所有配置变更都会立即保存，无需手动保存
